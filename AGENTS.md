# Commit messages

Use the user's commit message convention for all future commits in this repository:

- Small changes: a single line starting with `add:`, `fix:`, `feat:`, or `chore:`.
- Large changes: a concise first line summarizing the main change, a blank line, then detail lines using those prefixes. Use at most one line per prefix and omit categories that do not apply.
- Describe the actual changes in the commit. For the initial implementation, the main change is building the personal homepage framework.
